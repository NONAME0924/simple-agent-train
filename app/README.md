# 應用程式

[English](README.en.md)

後端程式入口與各職責模組。

| 檔案／目錄 | 用途 |
| --- | --- |
| `core/` | 協調流程；工具與儲存實作留在各自模組。 |
| `mcp/` | 通用程式可公開；實際 mcp.json 與憑證不提交。 |
| `storage/` | 管理本機資料，不在此資料夾保存使用者作品。 |
| `tools/` | 函式簽名同時產生 Schema 與參數驗證。 |
| `web/` | FastAPI 路由與瀏覽器資源。 |
| `__init__.py` | Python 套件入口；部分套件也在此匯出共用函式。 |
| `config.py` | 讀取 .env／環境變數，定義共用路徑、模型與預算設定。 |
| `logging_setup.py` | JSONL 日誌、類別與等級、專案／對話分流及輪替。 |

# Windows runtime

[繁體中文](README.md)

Local distribution runtime; Git keeps only these READMEs. Third-party directories such as Lib retain their own documentation and licenses.

| File/directory | Purpose |
| --- | --- |
| `DLLs/` | Third-party runtime contents with their own documentation and licenses. |
| `Lib/` | Third-party runtime contents with their own documentation and licenses. |
| `Scripts/` | Third-party runtime contents with their own documentation and licenses. |
| `tcl/` | Third-party runtime contents with their own documentation and licenses. |
| `LICENSE.txt` | License shipped with the Python distribution. |
| `python.exe` | Windows Python executable. |
| `python3.dll` | Python stable-ABI library. |
| `python312.dll` | Python 3.12 library in this local distribution. |
| `vcruntime140.dll` | Microsoft C runtime library. |
| `vcruntime140_1.dll` | Microsoft C runtime support library. |

Linux/macOS uses a project .venv instead of this Windows runtime. See the project README for Windows source setup.

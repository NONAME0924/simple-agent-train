外部工具

        
預設 Blender。先在 Blender 安裝並啟用插件，再按側欄的「Start MCP Server」，然後在這裡連線。

        下載 Blender 插件
        

        

        
連線綁定目前專案；一般對話各自綁定。同一實例同時供一個任務使用。沒有定時輪詢；修改 mcp.json 後請中斷再重新連線，修改 .env 後請重啟 Agent。

        
Agent 與 Blender 在不同電腦？
Blender 位址由 Agent 後端連線。Agent 在遠端時，127.0.0.1 指遠端主機；請先建立連到 Blender 電腦的 SSH 連接埠轉送，再使用對應的 BLENDER_HOST／BLENDER_PORT。
